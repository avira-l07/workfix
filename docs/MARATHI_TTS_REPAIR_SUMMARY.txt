iTantra Marathi offline TTS repair
Date: 4 October 2026
Repository: D:\new itantra

WHAT WAS WRONG
The old Marathi MMS-VITS voice lacks the trained token for U+0949 (ॉ).
The doctor phrase lost that vowel in raw synthesis. The previous app guard
made the failure explicit, but could not repair the voice's pronunciation.
Adding an arbitrary token or replacing the vowel would not fix trained weights.

WHAT CHANGED
Marathi TTS now downloads Piper mr_IN-google-medium, speaker 0, with an
offline eSpeak phoneme frontend. The trained graph and weights are unchanged;
download preparation appends 128 bytes of Sherpa metadata and installs the
trained single-codepoint phoneme IDs. Unsupported multi-codepoint token keys
were removed after the first conversion caused a native loader termination.
The final desktop model loaded and synthesized every targeted probe.

The Marathi manifest is now version 3.0.0. Raw model, archive, converted
model, tokens and required frontend files have pinned SHA-256 checksums.
ZIP extraction rejects traversal/duplicates/unrelated paths and excess size.
Downloads remain selective and staged before replacement. Old MMS-only
installs are marked incomplete and require the new Marathi TTS download.
Missing frontend data and foreign-alphabet text give explicit errors while
preserving the message. No runtime network API or native dependency was added.
Offline import now supports nested frontend paths. A six-file minimal import
produced valid desktop audio on all 17 tested texts.

Diagnostics shows the measured desktop references and keeps phone results
Not verified. Settings credits and saved TTS evaluation reports now identify
the Piper voice correctly. Installed storage counts include its frontend.

The raw MMS comparison bypassed the app guard and skipped U+0949 in all
six doctor trials. Non-silent legacy audio is not a pronunciation pass.
Piper produced finite, non-silent audio in 30/30 trials and all 12 character
probes. The separate 17-text phoneme check retained the doctor's ɔ vowel,
distinguished doctor/coffee spellings, and found no missing trained phonemes.
This checks signals and frontend coverage; TTS accuracy/MOS was not measured.
Cold model load did not improve. Desktop peak RAM includes runtime/libraries.

WHEN A PHONE IS AVAILABLE
Install the new APK. Download Marathi TTS in Language Packs. Keep the dedicated
Marathi STT pack and select Marathi mic. Disconnect internet and run Diagnostics.
Play/speak the doctor, oxygen, ambulance, coffee and numeral probes. Have a
Marathi listener record specific failures and ratings, then run the two-phone
offline test. Keep the status Not verified until those results are recorded.
